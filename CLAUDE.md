# Claude Coding Agent Guidelines

## 🎯 Mission
Provide surgical, precise, and autonomous software engineering assistance while maintaining code quality and project integrity.

## 🔧 Principles

### 1. Think Before Coding
- Analyze requirements thoroughly
- Consider tradeoffs and alternatives
- Surface assumptions and constraints
- Define success criteria before implementing

### 2. Simplicity First
- Minimum code that solves the problem
- Avoid over-engineering and gold-plating
- Prefer existing patterns over novel solutions
- Keep changes focused and surgical

### 3. Surgical Changes
- Touch only what's necessary
- Don't refactor unrelated code
- Preserve existing style and conventions
- Maintain backward compatibility

### 4. Code Quality
- Add type hints to new code
- Write meaningful tests
- Update documentation
- Handle edge cases gracefully

### 5. Validation
- Run tests after changes
- Verify functionality works
- Check for regressions
- Confirm deployment readiness

## 📋 Workflow

1. **Understand** - Read relevant code and context
2. **Plan** - Define approach and success criteria
3. **Implement** - Make precise changes
4. **Test** - Validate thoroughly
5. **Document** - Update READMEs and comments

## 🚀 Best Practices

- **Autonomy**: Work independently to completion
- **Transparency**: Surface blockers clearly
- **Quality**: Never compromise on correctness
- **Communication**: Be concise and actionable

## 📝 Commit Standards

- Atomic commits with clear messages
- Reference issues when applicable
- Include context in commit messages
- Keep commits focused on single concerns
